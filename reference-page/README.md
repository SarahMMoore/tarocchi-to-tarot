**Course:** GIT 414: Advanced Web Coding  
**Project Classification:** Educational Mini-Site & Content Resource Guide  
**Production URL:** [https://tarocchitotarot.com](https://tarocchitotarot.com)  

---

## 1. Executive Summary & Core Thesis
The purpose of this capstone project is to deliver a high-performance, accessible digital archive that challenges popular 20th-century cultural misconceptions of the Tarot deck. Rather than treating the deck as an ungrounded artifact of occult divination, this site presents a systematic breakdown of its history and its foundational role as a rigid, finite, and relational database structural model.

The narrative maps the historic progression of how early Chinese gaming cards evolved into Renaissance card matrix hierarchies  and serves as training datasets to benchmark machine learning algorithms.

## 3. Tech Stack & Frontend Design Parameters
To comply with the constraints of GIT 414, the site avoids student-authored JavaScript, heavy frameworks, or live runtime database queries. It focuses entirely on browser-native optimizations:

*   **Markup Foundation:** Strictly semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
*   **Layout Engine:** A custom, responsive fluid CSS3 infrastructure leveraging Flexbox and Grid. Fixed-width containers are banned in favor of fluid max-width boundaries.
*   **Typography & Flow:** Breakpoints are content-driven, optimizing line lengths (characters per line) to maximize text legibility across dynamic viewports.
*   **Aesthetic Profile:** A high-contrast, dark-mode design system utilizing clean technical typography and custom color variables for architectural highlights.

## 4. Production Deployment & Security Strategy
The infrastructure is designed for low overhead, high availability, and secure modern release standards:

*   **Version Control & Repository Host:** Managed locally through GitHub Desktop and hosted in a clean, synced cloud repository.
*   **Production Hosting Stratum:** Static deployment using GitHub Pages.
*   **Domain Name Management:** Configured via an apex domain string (`tarocchitotarot.com`) registered through Spaceship, mapping traffic through a pooled matrix of GitHub load-balancing IP addresses (`185.199.108.153` through `.111`).
*   **Encryption (HTTPS):** Enforced globally via an automated SSL/TLS handshake certificate managed through the GitHub Pages servers.
